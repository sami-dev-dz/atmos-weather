# Atmos Weather App

A beautiful, responsive weather application built with Next.js, React, and Tailwind CSS.

## Overview

Atmos Weather App provides real-time weather information, detailed forecasts, and location-based weather tracking with a sleek, modern interface.

## Features

- Real-time weather data
- Detailed forecasts
- Location search
- Responsive design
- Modern UI/UX

## Technology Stack

- Next.js
- React
- Tailwind CSS
- TypeScript

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
